# AI协作、授权与恢复合同

2026-10-02；对应体验重构v1.1实际实现。本文件描述当前行为，不代表60项验收全部通过。

## 用户选择

旧项目默认“逐项审阅”，不自动改成智能模式。用户在AI准备入口明确选择项目协作方式：

- **AI先安排**：新导入且尚无正式片段时整理可撤销初稿；已有章节只补充表演建议，不重建片段。明确出处、无歧义的说话人和短中性表演可应用；保留其他疑点。
- **逐项审阅**：新增语义设置保存在分析草稿，用户采用后生效。有效编辑仍自动保存，确定性预检仍自动运行。

当前中性表演仅接受40字以内的限定词组合，如“自然、清楚地表达”。强烈情绪、额外发声、音效和音乐不自动采用。新角色可形成未配声音的初稿；智能准备不会代选新声音、付费创建候选、成组或采用场景事件。

## 来源、人工保护与资格

新流程记录`human`、`inherited`、`policy_ai`、`system`来源。角色和声音决定保存当前绑定值；AI安排保存输入修订、策略版本、草稿与变更引用。旧记录保留原布尔资格，不补造历史人工来源。

用户改过的正文、角色、声音、表演等字段受保护。后续准备不覆盖这些字段，不把已保护或已等效的表演重复列为必需确认。详细分析中的“允许AI下次安排这句表演”只解除所选句表演保护，当前表演仍保留。

生成、章节状态及导出使用相同配置资格函数。新声音选择是明确的人为决定；本章继承角色声音记录为`inherited`。说话人仍有疑点时，仅选声音不能替用户确认说话人。所有来源均不能代替人工声音听评。

撤销仅恢复仍与这次AI安排对应的耦合设置；后续相关改动返回冲突，不覆盖新编辑。原文、片段ID、声音文件和历史保留。改变协作策略停止后续自动采用，不强行撤销既有安排。

## 本章选声

单句入口默认只改这一句。角色入口显示本章沿用该角色声音的范围，单句覆盖保留。

已绑定角色换声默认存为章节角色声音，不影响项目未来默认或其他章节；新建、改绑及重置继承均读同一章节映射。首次绑定沿既有规则补齐本章及建立未来默认。高级角色默认设置仍是明确的独立动作。

## 外发与预算

首次外发前用户确认项目/章节、素材类别、用途、模型/接口、文本与音频请求次数及有效期。授权不自动开始任务。当前UI授权有效24小时，可撤回；金额以供应商账单为准。

文本和音频分别计数，包含预留和已用。免费计划使用实际文本分批及声音单元去重；匹配声音可复用，实际编排中的干声与场景可在一个任务内按各自模式生成。章节修订或编排版本变化使已展示范围失效。

所有新增付费组合动作要求授权。项目启用新协作方式后，旧分析/生成入口同样检查授权，不能绕过。最终发送处再次检查撤回、过期、模型/接口和参考范围；未发送项释放预留，已发送及结果不明按已用保留。

普通生成没有通用重复计费勾选。`unknown`重试和恢复暂停接口只接受用户明确选择；不会默认传`retryUnknown:true`或无限重试。

## 保存与组合操作

关键动作先等待相关有效草稿保存。正文临时为空、数字未填完等保留本机；仅明确“不朗读”才能把空白正文应用为排除，组结构规则仍生效。同页只有已确认的修订回执可承接排队编辑；外页冲突保留草稿。

保存、准备、选声、成组生成、场景生成、候选和导出使用持久操作标识。丢响应先查询同一操作，不能直接重发付费请求或复制对象。

- 组已创建但入队失败：保留待生成组和旧实际编排；从该组继续。
- 候选已入库但绑定冲突：保留唯一音色，再核对目标绑定。
- 场景事件已采用但生成失败：保留目标设置及旧实际声音版本。
- 上传参考丢响应：`uploadId`同时作为声音主键，查询回执恢复；同ID异素材拒绝覆盖。
- 导出：使用当前实际声音及人工检查依据，同一母版导出，不调用配音模型。

## 对应后端入口

| 用途 | 接口 |
|---|---|
| 查看协作、授权、可撤销安排 | `GET /api/projects/:id/experience` |
| 修改策略、授权、撤回 | `POST /api/experience/policy`、`grant`、`revoke` |
| 撤销安排、解除单句表演保护 | `POST /api/experience/undo`、`unprotect` |
| 免费执行计划 | `POST /api/operations/plan` |
| 保存与任务组合、查询回执 | `POST /api/operations`、`GET /api/operations/:id` |
| 上传参考、查询上传回执 | `POST /api/voices`、`GET /api/voices/:uploadId` |

原详细分析、批次恢复、历史版本和人工听评接口保留既有校验。真实模型效果、完整浏览器矩阵和人工听评须以独立验收证据为准。
