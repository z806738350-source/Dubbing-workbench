## 已采用的具体决定

| 编号 | 决定 | 原因及实际影响 |
|---|---|---|
| D01 | 四步制作与章节状态主动作 | 让用户按任务前进；内部待生成组、变体、检查和母版构建由程序衔接。详细设置与恢复仍可发现。 |
| D02 | 角色选声在同一抽屉完成 | 声音库、上传和描述创建共同展示实际范围；默认只改本章继承声音，保留单句指定。首次角色绑定沿原规则作为未来新片段默认，并在界面明确说明。 |
| D03 | 场景配置在生成前、事件内联 | 环境／音效／音乐可组合；实际播放版与待制作目标分开展示。加入事件不收费，生成才用授权；切回已有纯人声不暗中补录。 |
| D04 | 有效输入自动保存，关键动作等相关编辑 | 600ms防抖及IME保护；空正文／未完成数字留本机。只沿本页确切回执推进，跨页改动仍冲突；保存失败不吞续写。 |
| D05 | 普通授权范围复用，例外明确决定 | 项目／章节、模型、参考、次数和有效期可见；撤回阻止后续请求。unknown批次／音频及暂停路由的恢复不得由普通按钮隐式决定。 |
| D06 | 丢响应与部分成功沿稳定对象继续 | 对话创建成功则打开同组；候选入库而绑定失败复用同声；上传仅持久ID与文件元信息、不存录音字节；复用原操作回执不因范围变化另发未知请求。 |
| D07 | 收紧首屏与保留阅读调节 | 标题和工具紧凑，17px完整正文优先。1440px目录实际208px、详情350px；不同于规格的起点值，属于允许的视觉裁量。D07实机305条，17→34px仍可读；原1280×800与960／1440内嵌harness已留图。不混用720、800和900高截图宣称首屏改善比例，正文尺寸200%不等同于全界面缩放200%。 |
| D08 | 40—44px主要动作目标、双密度 | 章节主要按钮42px，任务footer44px；次级按钮可紧凑。密度不改字号、功能、音频或范围。完整可访问性仍需真实核验。 |
| D09 | 一个活动遮罩、内容滚动、主动作固定 | 原生Dialog保留父上下文并恢复焦点；事件／草稿内联。`scene-final-1280.jpg`已显示授权在body、范围与生成在footer。主执行者实际Enter打开选声、Escape关闭并返回同一触发焦点；未将该子场景扩称全部键盘路径通过。 |

## 实现与样板差异

当前工程使用既有token／组件并追加统一体验样式，尚有历史级联规则，不能声称已完成全部样式清理。相对初始图，授权已移至body、成员可“修改这句”、新事件／声音描述移交稳定ID保留光标、选声范围变更后重新核对。最终章节和场景截图已补录；它们展示当前任务状态，不替代严格同数据对照。

最终视觉复核使用已保存图片和主执行者实机记录，不另操作用户库。原浏览器DOM测量是1280×800；960×900与1440×900通过内嵌harness执行，未声称IAB viewport API真正调整外层窗口。D07的305条与17→34px、目录／详情的折叠恢复和固定播放器已在所列画面检查，没有发现需要继续生产修改的可见阻断。尚未覆盖的更窄窗口、完整组件状态、完整键盘／读屏／全界面缩放及人工视觉签收继续按VS矩阵标记，不为缺少证据虚构通过或新增审美门槛。

执行团队的试走、组件函数回归、真实浏览器操作、真实供应商结果、真实新手与人工视觉签收分别记录。供应商听评和精致度没有自动断言的替代物；不虚构点击减少比例、任务完成率或留存提升。
