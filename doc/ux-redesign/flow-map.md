# 工作台任务流与返回位置

2026-10-02；按当前组件和后端合同整理。此图是功能入口说明，不代表所有场景已经验收。

## 正常制作

`项目/章节 → AI准备 → 需要你处理 → 生成待办 → 试听与修改 → 导出`

| 任务 | 入口与对象 | 主动作与范围 | 成功/失败后的去向 |
|---|---|---|---|
| 首次体验与导入 | 首屏、项目总览、导入；TXT/Markdown或粘贴 | 导入新章保留原文；AI路径暂不建正式片段 | 到本章AI准备；仅导入可直接人工分段。免费演示只体验播放器，标明非模型效果 |
| AI准备 | 本章“AI准备” | 选择项目协作方式；显示实际文本请求数；准备整章或所选片段 | AI安排和疑点摘要留在原处；疑点可前往具体句或问题中心；无效结果保留可读草稿 |
| 为角色选声 | 问题中心、单句、角色选声入口 | 已有声音/上传/描述创建集中展示；单句或本章角色继承范围 | 用声后回原位置；候选入库后绑定失败可继续使用已保存音色 |
| 生成待办 | 本章主动作或所选台词 | 展示实际单元、成员、模式、复用和新请求次数；保存后发送 | 任务栏显示结果；失败保留已有声音；结果不明到具体任务，明确决定后再发 |
| 一起演绎 | 选中连续台词后的任务工具条 | 检查真实连续/冲突；共同指导与生成在同一面板 | 成功激活整组；只创建成功则打开待生成组继续；取消组预览各句干声，历史保留 |
| 声音背景 | 单句或组的声音面板 | 共同指导、事件、AI场景建议、采用和生成集中处理 | 新场景成功后成为实际版本；失败保留目标与旧版本。没有事件不隐式改成干声 |
| 返工与导出 | 单句/组面板、章节试听、导出 | 改动后仅更新受影响单元；用户明确确认当前实际声音；WAV/MP3同源 | 历史可比较/恢复；正式导出条件不足时定位问题；仅本地处理不计模型请求 |

## 用户需要判断的位置

“需要你处理”按角色聚合说话人和缺声音，显示原文与定位动作；结构/覆盖问题到原文或编排，未知请求到任务记录，听评返工到受影响声音。AI表演建议是可选创作判断，不等于阻断配置问题。

本章声音面板保留高级表演/数值、模板、历史、干声/场景切换。高级整理保留人工校对、批次恢复和替换原文：只生成草稿，明确应用前不替换正式内容。

## 中断、草稿与返回

有效编辑自动保存并显示状态；未完成输入保留本机。关键动作等待对应草稿，冲突时不抹掉输入。侧栏关闭不影响已入队任务；“本机暂存与恢复”按对象定位未保存编辑。跨页未确认版本不能被同页队列静默承接。

| 已完成部分 | 下一步 |
|---|---|
| 保存响应丢失 | 查询同一操作回执，再承接保存版本 |
| 对话范围已保存、生成未入队 | 继续该待生成组，不再建第二组 |
| 候选已保存、目标绑定冲突 | 重新核对目标，复用同一候选音色 |
| 参考上传响应丢失 | 查询稳定上传ID，恢复唯一声音记录 |
| 声音背景目标已保存、请求失败 | 旧实际版本可继续试听；修复后只重做该版本 |
| 部分文本批次完成 | 复用已收到部分，授权后继续未完成批次 |
| 供应商结果不明 | 查看现有记录；用户明确决定才再次提交 |

## 组件落点

`App.tsx`负责章节主流程、计划与任务入口；`WorkspaceExperience.tsx`负责总览、问题、选声、恢复和入门；`AnalysisDialog.tsx`负责智能准备及详细校对；`UnitPanel.tsx`负责一起演绎与声音背景；`VoiceCreation.tsx`负责候选生命周期；`ObjectDraft.tsx`/`autosave.ts`负责保存与屏障；`TaskAuthorization.tsx`/`taskOperations.ts`负责明确授权和可恢复操作；`server/experience.mjs`协调持久记录，复用原分析、生成、声音和导出能力。
