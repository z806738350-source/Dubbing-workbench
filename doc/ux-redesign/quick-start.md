# 四步完成一章配音

适用于 macOS 本机体验升级版。双击已有“启动配音工作台.command”；使用独立体验包时，解压后双击“启动体验版.command”。使用期间保留启动窗口。

第一次可点“免费试听演示”熟悉播放器。演示来自本机语音，不代表 Seed Audio 模型效果，也不会产生模型费用。真实 AI 准备和配音前，到“设置与连接”检查接口和音频处理状态；缺少配置时按包内 README 完成。

## 1. 导入文字

新建或选择项目，点“导入章节”，选择 UTF-8 的 TXT、Markdown（文件最多 4 MB），或直接粘贴原文。勾选“导入后进入AI准备”，然后点“导入并进入AI准备”。原文会保留，可随时查看；非空导入草稿关闭后仍可找回。

导入中断后，回同项目的导入面板点“恢复这次导入回执”；若已创建，点“打开已导入章节”。这会恢复同一次导入或打开原章，不另建一章，也不自动发起 AI 请求。提示未可靠暂存时，先复制原文保留。

## 2. 让 AI 准备

在本章“AI准备”选择协作方式：“AI 先安排”会把明确的说话人与常规表演安排进初稿，留下疑点供你处理；“逐项审阅”先保留建议，等你审阅后应用。AI 安排不会替你标记听评通过，也会保留你手工修改的内容。

查看文字外发范围和请求次数，点“允许上述范围”，再点“准备这一章”。正常操作会复用仍有效、范围相符且额度足够的授权；改变范围、额度用完、授权到期或撤回后需重新允许。允许范围本身不会开始生成。“还可请求”是授权剩余次数，不是账户余额；已发送失败或结果不明的请求仍占用额度。

## 3. 集中处理问题和选声

点“需要你处理”，按角色处理说话人疑点和缺少声音。点“选声音”，可以试听已有声音、上传参考录音，或用描述创建候选；试听满意后再用。

换声时先看“应用范围”：“角色在本章”只更新本章沿用角色声音的台词，保留单独指定过的句子；“仅这一句”只改当前句。首次为新角色绑定声音也会建立未来新增台词的默认声音，界面会提示。

## 4. 生成、试听、修改和导出

点“生成待办”，看清这次要制作哪些句子、哪些声音会复用及新请求次数，允许范围后开始制作。完成后逐句或整章试听；有读错、声音不合适或表演问题，修改受影响内容后重新制作。改一段“一起演绎”中的一句，会重做整段。顶部“重做否决项”安排已标记重做的声音单元；普通所选范围中，其他匹配声音会复用。

检查当前实际声音并记录听评结果，再点“导出成品”，选择 WAV 或 MP3，点“确认检查并导出”。面板留在原处显示结果，在“已导出的文件”按实际编排和完成时间下载“当前结果”；也可关闭后再打开。这个按钮会将当前匹配音频的待检查项确认为通过，应先实际试听。两个格式使用同一母版，导出本身不再调用配音模型。若提示缺声音、正文覆盖或编排问题，按定位入口先处理。

## 常用入口与中断处理

| 想做什么 | 从哪里进入 |
| --- | --- |
| 多人自然接话 | 勾选两条或更多连续对白 → “一起演绎” |
| 加环境、音效或音乐 | 选中一句或一组 → “声音背景” |
| 对比或恢复旧声音 | 单句“历史与版本”，或声音面板展开“历史声音 · …版” |
| 找回没完成的编辑 | 左侧“本机暂存” → 查看对应内容 → “恢复并返回编辑” |
| 看失败、进度或结果不明 | 左侧“任务记录” |
| 查看保存目录和连接 | 左侧“设置与连接”；“核对资料与空间”查看文件数量、大小和缺失项 |

声音面板上方“整章使用”表示真正进入整章试听与导出的版本。历史声音先“试听声音…”；匹配的可“使用声音…”，旧设置先“核对并恢复声音…”查看表演、背景和模板差异，再决定“恢复并使用这份声音”。未采用的背景草稿保留；不兼容的旧版本仍可试听，不能恢复使用。当前或历史声音播放时，原按钮会变成暂停，可直接在面板内操作。

添加背景仍属试验。“背景存在感”的轻、自然、清楚只在下一次使用“场景 v4 · 背景存在感（试验）”生成时生效；旧模板先点“核对存在感模板差异”，比较后明确“使用这个模板”，不会自动升级。旁白／对白与采用的背景仍由模型一次联合生成。必须人工试听正文、背景可辨程度和音乐转折，选“清楚”或请求成功不代表听评通过。

有效输入会自动保存，留意“已保存 / 保存中 / 本机暂存”的状态。中文输入尚未结束、未完成的空正文或数字会先留在本机；继续填完整即可保存。生成等主动作会等待相关编辑保存，关闭面板不等于丢弃草稿或取消已发送任务。

发生冲突时，先比较“本页编辑”和“工作区当前内容”，再选择用本页编辑更新，或“保留工作区内容”；不要靠刷新反复碰运气。需要保留文字时，可以先复制出来。

“结果不明”表示供应商可能已经收到请求并计费。先“查看这次记录”并“试听已有声音”；选用旧声音不会清掉未确认请求。决定重发时才勾选计费提示，再明确点生成按钮。连接中断、本地服务失败或回执无法读取时，也先核对原操作和已有结果，不立即再次生成。声音接口暂停时，先核对权限和额度，再在原面板明确恢复本次请求；授权有效与接口可用是两件事。

本机暂存按打开地址和实际工作区区分。改端口、在生产／开发入口之间切换，或打开另一个备份目录前，先在原入口保存或复制编辑；旧暂存不会自动带入新库。归属未确认的旧版暂存可查看、复制或明确放弃。完整恢复、历史复用、迁移和删除范围说明见 [工具使用说明](../工具使用说明.md)。

退出时在启动窗口按 Control+C，等安全停止完成。仅关闭浏览器不会停止服务。需要备份时，停服后备份“设置与连接”显示的整个保存目录。
