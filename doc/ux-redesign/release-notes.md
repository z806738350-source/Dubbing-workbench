# 配音工作台体验升级说明

2026-10-02 · macOS 本机内部试用。未公开上线，也未向其他用户发送分发包。

本轮把制作入口集中到“导入文字 → AI准备 → 试听与修改 → 导出成品”，章节会提示下一步。说话人疑点和缺声音集中在“需要你处理”；选声、一起演绎和声音背景可在同一任务面板内完成，详细设置及历史继续保留。

## 本轮变化

- 审核补修：生成在参考音频预检等待期间若被另一页切换版本，会停止并提示重新核对；单句确认只登记所选台词的人工来源；问题中心会列出对戏和声音背景的最新结果不明，并直达对应版本，保留旧声音试听。
- 有效编辑自动保存；输入法过程、临时空正文和未完成数字先保留本机。保存状态、两份内容冲突比较和“本机暂存”恢复入口可见。
- 可选择“AI 先安排”或“逐项审阅”。常规内容可自动进入初稿，疑点与人工改动保留；声音选择和人工听评仍由用户决定。
- 集中试听已有声音、上传参考与描述创建候选。已有角色换声默认限定本章，也可只改一句；首次绑定会提示未来新增台词的默认声音。
- 一起演绎、声音背景、历史及版本集中呈现。生成失败保留已有结果，响应未确认会查询原操作；供应商结果不明必须明确决定才重发。
- 生成前显示范围和请求次数；正常操作复用有效且额度足够的授权。免费演示使用本机语音，供体验播放器，不是模型效果样本。
- 统一任务面板、主要动作和保存提示；较窄桌面窗口可展开导航与编辑面板。完整验收状态以 `acceptance-matrix.md` 为准。

原有一键启动、项目保存目录、旧服务复用和安全停止补丁继续保留，独立体验包新增预构建启动入口，不替换原开发启动流程。用户资料不随体验包分发。

原目录、联合备份及兼容副本已对照：3 项目、5 章、5 角色、313 片段与单元的完整记录保留；6 音色、10 音频、4 母版、4 导出对应的 24 个重要文件一致。仅兼容副本执行当前迁移读取，未改变业务记录。详细范围见 `compatibility-check.md`。原 4318 浏览器草稿来源保留，本次文件对照没有迁移或清理该 origin 的存储。

独立 macOS ZIP 已隔离解压启动验证，包内无需 npm 安装或重新构建。**Node.js 22.13+、FFmpeg 与 FFprobe 未附带，需本机已有。** 启动文件与 README 会说明缺失项；新资料默认存在解压目录的 data，实际保存位置可在“设置与连接”查看。最终包清单与验证范围见 `distribution-check.md`，后续构建须同步重打包。
