# Ardot 前端设计规范归纳 v0.1

日期：2026-09-24\
性质：参考产品的设计规范研究，包含实际界面观察、局部 CSS 实测和归纳规则。\
当前目的：总结前端设计规范。本文不制定配音业务流程，不决定组件库，不展开配音工作台页面设计。

## 1. 范围与证据口径

来源为 [Ardot 官网](https://ardot.tencent.com/)、经用户授权读取的 [文件工作区](https://ardot.tencent.com/drive/recent)，以及其中现有的“产品介绍”示例文件。通过用户的 macOS Chrome 查看真实界面，并用浏览器开发者工具只读检查局部样式。没有修改示例文件内容、提交 AI 请求或执行导出。

本文不是腾讯官方发布的设计系统。以下三种依据分别标明：

- **实测**：读取具体元素的计算样式或页面内联样式，只对指定元素和当前状态成立。
- **声明**：在页面加载的样式中发现的变量或类名；不等于已经验证所有组件实际采用这些值。
- **观察／归纳**：从真实界面及交互提炼的关系和使用原则。未测量的数值不以“官方参数”补齐。

尺寸均按读取到的 CSS px 记录。截图像素、屏幕缩放、浏览器缩放和 CSS px 不能直接等同；画布内的 12% 是设计稿缩放，也不是浏览器缩放。

## 2. 总体设计原则

**内容占据视觉中心，工具保持中性；位置保持稳定，功能随上下文变化。**

1. **白灰承载，彩色聚焦。** 常驻面板以白色和浅灰为主，绿色用于当前导航、选中对象和激活工具。
2. **按工作阶段调整密度。** 文件管理页留白较多；编辑器参数区紧凑；AI 面板为输入和阅读增加宽度。
3. **分区先于装饰。** 用位置、分组、间距和细线组织复杂内容，少依赖整块阴影卡片。
4. **常驻与临时操作分开。** 全局工具长期可见，对象相关操作随选择出现，菜单短暂覆盖内容。
5. **选中必须有对象对应。** 左侧选中行、中央选择边框、右侧属性针对同一个对象。
6. **圆角分等级。** 小型字段、分组容器、悬浮工具栏采用不同程度的圆角。
7. **表面主题按组件职责区分。** 浅色编辑器中可以出现深色菜单，不能据此判定整个页面进入深色模式。

这些是跨样本归纳的设计原则，不代表已取得产品完整设计系统。

## 3. 页面结构规范

### 3.1 文件管理页

观察结构：左侧账户与导航，右侧文件内容；内容区自上而下为问候、创建／导入入口、列表标题与筛选、文件网格。

归纳规则：

- 全局导航固定在左侧，当前位置使用整行浅色底标识。
- 个人文件入口、快捷访问、团队入口分组展示，组间使用留白和细线。
- 创建和导入入口是“图标＋标题＋短说明”的操作卡片。
- 文件卡片采用“预览图在上、名称和元信息在下”的结构；预览图有圆角和轻边界。
- 筛选与排序靠近文件列表标题所在行，避免混入全局导航。
- 文件集合按网格对齐；本次宽屏样本为四列，不将四列写成所有屏宽下的固定规则。
- 加载占位沿用将要出现的导航、入口和卡片结构，减小加载前后的视觉跳动。

### 3.2 编辑器

观察结构：左侧文件／组件与页面图层，中间画布，右侧属性／AI；顶部中央为悬浮工具栏，右上为预览和分享，画布右下为缩放与视图控件。

归纳规则：

- 结构导航、主要内容、对象设置分别占据固定区域。
- 侧栏内容可独立滚动，保持编辑器外壳稳定。
- 工具栏使用横向胶囊容器，减少对画布的遮挡。
- 选中对象时在常用工具旁增加上下文工具，不把所有对象操作永久展开。
- 未选对象时显示页面级属性；选择对象后显示该对象的属性分组。
- 不把画布内容本身的背景、照片或装饰误当作应用主题。

### 3.3 AI 辅助面板

归纳规则：

- 与手工属性共用右侧工作区域，通过页签切换。
- AI 模式适当增加面板宽度，中央内容仍保留可见区域。
- 空态包括简短身份说明和可选的指令示例。
- 输入区固定在面板底部，模型选择和发送操作靠近输入区。
- 选中对象以引用标签显示，让用户知道当前请求关联的内容。

本次只查看了空态和对象引用，没有验证生成中、回复、失败、历史会话及结果采用流程。

## 4. 颜色与表面层级

### 4.1 颜色角色

| 角色 | 观察或实测 | 归纳用法 |
|---|---|---|
| 主面板 | 白色 | 承载目录、属性和正文 |
| 次级表面 | 浅灰；输入框实测 `rgba(0,0,0,0.04)` | 表示可编辑字段、分段切换底槽等局部区域 |
| 主要文字 | 数值输入框实测 `rgba(0,0,0,0.9)` | 保持主体内容清晰 |
| 次要文字 | 灰色，未逐项测量 | 承载目录来源、更新时间、说明 |
| 选中底色 | 浅绿色 | 标识当前导航项或图层 |
| 强选中反馈 | 明亮绿色的边框、工具底色 | 标识当前工具或画布对象 |
| 主要按钮 | 黑／近黑底、浅色文字 | 分享等重要操作；不能把所有主要操作统一推断成绿色 |
| 临时菜单 | 混合模式菜单为深灰底、浅色文字 | 与常驻白色属性面板分层 |
| 菜单当前项 | 绿色底＋勾选 | 同时用颜色和形状表达选中 |
| 分隔线 | 低对比灰色 | 区分属性组和导航组 |

### 4.2 已读取的语义色声明

以下保留原变量名称，作为其分层方式的证据。变量引用未逐一解析的地方不填猜测色值。

| 页面变量 | 读取到的声明 | 含义 |
|---|---|---|
| `--cd-color-bg` | `var(--white-1000)` | 主背景 |
| `--cd-color-bg-desktop-web` | `0 0% 100%` | Web 外壳背景的 HSL 分量 |
| `--cd-color-bg-drive-sidebar` | `0 0% 96.08%` | 文件管理侧栏背景的 HSL 分量 |
| `--cd-color-bg-canvas` | `0 0% 96.08%` | 画布基础表面的声明；可被文件背景覆盖 |
| `--cd-color-bg-input` | `var(--cd-color-bg-secondary)` | 输入框底色 |
| `--cd-color-bg-secondary` | `var(--black-100)` | 次级表面 |
| `--cd-color-bg-input-hover` | `var(--cd-color-bg-secondary-hover)` | 输入框悬停底色 |
| `--cd-color-bg-secondary-hover` | `var(--black-200)` | 次级表面悬停 |
| `--cd-color-bg-input-disabled` | `var(--cd-color-bg-secondary-disabled)` | 输入框不可用底色 |
| `--cd-color-bg-item-selected` | `var(--green-gray-600)` | 当前项选中底色 |
| `--cd-color-bg-tab-list` | `var(--black-100)` | 页签底槽 |
| `--cd-color-bg-tab-active` | `var(--cd-color-bg)` | 活动页签底色 |
| `--cd-color-bg-menu` | `var(--gray-900)` | 菜单背景 |
| `--cd-color-bg-button-primary` | `var(--cd-color-bg-inverse)` | 主要按钮背景 |

样式中另有品牌色阶声明，例如 `--brand-500: 138 68% 54%`、`--brand-600: 140 82% 44%`、`--brand-brand-color: 135 82% 44%`。这些是 HSL 分量声明，不能未经解析和组件取样就指定为所有绿色选中项的实际颜色。

**可复用规则：颜色按“用途＋状态”命名。** 输入框、菜单、按钮、选中项分别引用语义色，避免在组件里散布相近却不一致的灰色和绿色。

## 5. 字体与文字层级

### 5.1 已读取的字体栈

页面声明的 `--font-family-main`：

```text
"Inter", -apple-system, BlinkMacSystemFont, system-ui,
"pingfang SC", "hiragino sans gb", "microsoft yahei ui",
"microsoft yahei", "helvetica neue", arial, ui-sans-serif
```

X 数值输入框的 Rendered Fonts 显示 `Inter-Regular`，实际渲染了该字段中的四个数字。中文实际使用哪个回退字体尚未逐项验证，不能据字体栈断言所有中文都使用同一字体。

### 5.2 字号变量

| 声明名称 | 值 |
|---|---:|
| `--text-sm` | 11px |
| `--text-base` | 12px |
| `--text-lg` | 13px |
| `--text-xl` | 14px |
| `--text-2xl` | 16px |
| `--text-3xl` | 18px |

以上是编辑器中读取到的变量，不是官网大标题的字号表。类名 `text-sm`、`text-base` 在此有产品自己的定义，不能直接套用其他框架的默认字号。

### 5.3 已实测样本

| 对象 | 字号 | 行高 | 字重 | 字距 |
|---|---:|---:|---:|---:|
| 位置 X 数值输入文字 | 11px | 18px | 400 | 0.11px |
| 该输入框外层计算样式 | 12px | 20px | 未单独记录 | 未单独记录 |

子元素可以覆盖父容器字号，因此不能从容器的 12px 推断输入数字也是 12px。

归纳规则：界面标题、分组名称、字段值、辅助说明分层；分组主要通过字重和空间建立层级。紧凑参数适用小字号，但本次样本不支持把 11px 作为长文本阅读的通用规范。

## 6. 尺寸、间距与圆角

### 6.1 已实测与读取的局部尺寸

| 项目 | 数值 | 依据及适用范围 |
|---|---:|---|
| 数值输入框高度 | 28px | E07 外层及 input 计算样式 |
| 数值输入框圆角 | 6px | E07 外层四角计算样式 |
| 数值输入框当前宽度 | 96px | 当前双列布局样本，不作为固定宽度规范 |
| 数值文字右内边距 | 8px | E07 input 计算样式；左侧另有字段标识 |
| 右属性栏宽度 | 264px | E08 当前设计模式内联样式，不是所有模式通用宽度 |
| 中央内容左侧预留 | 252px | E08 内容区 `margin-left`；不等于已测定侧栏自身宽度 |
| 中央内容右侧预留 | 264px | E08 内容区 `margin-right` |
| 右栏上下内边距、间隙 | 各 8px | E08 右栏内联样式 |
| 工具栏距工作区域顶部 | 20px | E08 工具栏容器内联样式 |
| 部分参数行末尾图标列 | 28px | E08 `1fr 1fr 28px` 网格声明 |

当前证据体现出紧凑控件和局部间距的复用，但不足以宣称全站严格遵循某一种 4px／8px 网格体系。

### 6.2 圆角变量

| 声明名称 | 值 |
|---|---:|
| `--radius-xs` | 1px |
| `--radius-sm` | 2px |
| `--radius-default` | 4px |
| `--radius-md` | 6px |
| `--radius-lg` | 8px |
| `--radius-xl` | 12px |

页签还出现了 `rounded-[44px]` 类名，视觉呈胶囊形。它是局部胶囊处理，不应并入普通输入框的圆角等级。右侧栏外壳的内联圆角为 0px，说明并非所有面板都做成独立圆角卡片。

### 6.3 边界与阴影

- 属性分组使用低对比细线，部分 DOM 类名包含 `border-[#14181e14]`；尚未逐项测量边线计算宽度。
- 悬浮工具栏、AI 输入容器和展示容器有轻阴影的视觉效果。
- 常驻列表和参数分组以背景、分隔线与间距组织，不逐组叠加明显阴影。
- 阴影的精确偏移、模糊、扩展、透明度未作为已实测参数记录。

## 7. 组件规则

| 组件 | 结构和默认表现 | 状态规则及边界 |
|---|---|---|
| 侧栏导航项 | 图标＋文字，整行可定位 | 当前项浅绿色底；不把品牌装饰色用满整个侧栏 |
| 图层树行 | 层级缩进、展开入口、类型图标、名称 | 选中行浅绿色；与画布选择边框和右侧属性联动 |
| 分段页签 | 浅灰底槽、白色活动项、胶囊外形 | 在同一工作区切换内容，保留当前位置的空间关系 |
| 主要按钮 | 深色填充、浅色文字、圆角 | 已观察分享按钮；加载和失败状态尚未采样 |
| 图标按钮 | 线性图标，弱背景或无背景 | 激活工具可用强色底；危险操作和未知图标不能仅凭造型推断 |
| 数值输入 | 左侧字段标识、右侧数值、浅灰底 | 高度与圆角已实测；悬停／禁用存在样式声明，焦点完整效果未验证 |
| 成组字段 | 相关字段并排，对齐固定列 | 两个弹性字段可配一个固定图标列；避免每行随意改变结构 |
| 属性分组 | 标题行、内容行、细分隔线 | 依据对象显示分组，避免无关设置占满默认面板 |
| 下拉选择 | 控件内显示当前值与下拉箭头 | 混合模式浮层深色，当前项绿色＋勾选，选项按组分隔 |
| 复选框 | 方形标记＋文字说明 | 已观察深色底白色勾选；不能据此将所有选中控件规定为绿色 |
| 文件卡片 | 预览、名称、元信息 | 预览和元信息分层；加载骨架保留对应结构 |
| 操作入口卡片 | 图标、标题、短说明 | 同级操作采用一致容器尺寸和对齐方式 |
| 上下文工具条 | 胶囊形浮层、图标横排 | 选择对象后出现相关操作；与常驻工具条保持关联 |
| AI 输入区 | 引用标签、文本区、附加入口、模型、发送 | 底部固定；选中对象可见，不隐藏输入上下文 |
| 空态引导 | 短说明＋推荐操作 | 给出可开始的动作；本次只观察 AI 初始态和快捷访问占位 |
| 骨架屏 | 中性灰块对应最终布局 | 表达加载结构，不作为加载成功或完整错误处理的证据 |

## 8. 交互与状态规范

### 8.1 已验证的关系

1. 选择图层会更新右侧属性，并显示画布选择反馈。
2. 选择对象后出现额外的上下文工具条。
3. 切换 AI 页签会改变右侧内容和占用宽度，画布继续可见。
4. 当前对象可在 AI 输入区形成可见引用标签；本次未发送请求。
5. 混合模式菜单展开后显示当前值；按 Escape 可关闭且未改变原值。
6. 文件工作区有加载骨架到真实内容的切换。

### 8.2 状态覆盖记录

| 状态 | 当前依据 | 文档采用方式 |
|---|---|---|
| 默认 | 多处实际界面 | 可归纳常态外观 |
| 选中／激活 | 导航、图层、工具、页签、菜单 | 可归纳颜色及结构反馈 |
| 悬停 | 输入框和次级表面变量声明 | 记录存在独立状态，不填未测色值 |
| 按下 | 部分按钮与表面变量声明 | 不等于已验证所有按钮反馈 |
| 键盘焦点 | 未完成专门采样 | 不宣称符合某项无障碍标准 |
| 不可用 | 输入元素的禁用类名与颜色声明 | 不把灰色说明文字自动归类为禁用控件 |
| 加载 | 文件列表骨架、编辑器加载提示 | 可归纳占位方式 |
| 成功／失败／校验错误 | 未触发相关业务 | 保持未验证，不编造提示样式 |

归纳规范应区分“选中”“焦点”“悬停”“禁用”，不能用同一个浅色底解释所有交互状态。菜单中的勾选与绿色组合，是已观察到的冗余表达方式。

## 9. 官网与工具界面的边界

| 方面 | 官网观察 | 工具界面观察 |
|---|---|---|
| 目的 | 展示产品与引导进入 | 管理文件与连续编辑 |
| 留白 | 大幅展示区和宽松间距 | 文件页舒展，属性区紧凑 |
| 色彩 | 中性外壳搭配彩色演示与浅色渐变背景 | 中性面板搭配状态强调色 |
| 容器 | 大型圆角展示框 | 功能侧栏、紧凑字段、悬浮工具条 |
| 主操作 | 导航中的胶囊按钮 | 分享、工具、属性操作分布在相应区域 |

不能把官网演示中的手机界面、彩色图像、光标演示效果，直接认定为 Ardot 编辑器控件规范。官网按钮出现过描边和深色填充两种外观，但本次未确定触发规则，不将其写成已验证的 hover 行为。

## 10. 防止错误归纳

- **不是所有绿色都同义。** 品牌装饰、工具激活、列表选择、画布边框应分别记录。
- **不是所有浮层都白色。** 已观察到深色混合模式菜单；也不能反推所有弹窗都深色。
- **不是所有选中控件都绿色。** 活动页签采用白色，复选框有深色勾选样本。
- **设计稿色值不是系统色值。** 示例页面的 `#4B4B4B` 背景、所选设计内容的 `#13B56B` 填充不作为应用主题证据。
- **声明不是最终生效值。** 样式中存在多组变量、回退色和兼容命名，应以具体组件计算样式优先；不能看到蓝色回退值就判定产品强调色为蓝色。
- **示例库不是技术栈证明。** 文件列表中的 Ant Design、TDesign、shadcn/ui 模板不能证明产品整体采用哪套组件库。
- **鼠标光晕来源未核实。** 截图中的光标高亮不纳入网站动效规范。
- **局部参数不能扩张到全站。** 28px 输入框、264px 属性栏等只描述当前编辑器样本。

## 11. 未验证项目与后续补充位置

| 项目 | 当前缺口 | 应补充的证据 |
|---|---|---|
| 全量颜色 | 部分语义变量仍为引用 | 对代表组件读取最终生效值，区分默认、悬停、激活 |
| 中文字体 | 已有字体栈，未核实实际回退 | 中文文字的 Rendered Fonts |
| 完整文字角色 | 已有字号变量，未逐一对应组件 | 标题、导航、说明、菜单的实测映射 |
| 完整间距 | 局部尺寸与布局已记录 | 文件页、目录、属性组和浮层的间距测量 |
| 弹窗与提示 | 尚无代表样本 | 普通弹窗、提示、错误、长文本和空集合 |
| 键盘操作 | 只验证了菜单 Escape | 焦点可见性、Tab 顺序、页签和菜单的键盘行为 |
| 窄屏适配 | 仅有桌面样本 | 不同视口下的侧栏、工具栏、内容和浮层表现 |
| 动效 | 未进行时间与样式测量 | 过渡属性、时长、曲线和减少动态效果的处理 |
| 对比度 | 未做系统测量 | 各文字／控件状态与实际背景组合的测量 |

这些项目是规范研究的覆盖边界，不是要求扩建产品的功能清单。

## 12. 本版交付结论

本版已经将实际样本整理为可查阅的**页面结构、颜色角色、字体与字号、尺寸圆角、组件、交互状态**规范，并为局部参数保留证据范围。可作为后续继续测量与审核的研究依据。

尚不能将本文标为“Ardot 全量官方规范”或“所有参数和状态已经验证”。后续仍以补齐前端设计规范为目标，在对应章节更新证据，不转入业务功能扩展或应用页面实现。
