# 配音工作台使用说明

适用版本：macOS 本机体验升级版（2026-10-02）。支持单句配音、声音创建、多人一起演绎和声音背景；多人及场景效果仍需试听评估。快速开始见 [四步入门](ux-redesign/quick-start.md)。

**打开工具**：macOS 双击项目根目录的「启动配音工作台.command」，浏览器会自动打开普通工作区。首次使用需安装 Node.js 22.13+ 和 FFmpeg；启动项会准备项目依赖。使用期间保留启动窗口，停止按 Control+C；重复双击会打开已运行页面。此入口不会切换到文末的独立听评工作区。

## 先完成一章

1. **导入文字**：新建或选择项目，点「导入章节」，选择 UTF-8 的 TXT / Markdown，或粘贴原文。检查章节名和预览，再点「导入并进入AI准备」。Markdown 按纯文本读取，原文保留。
2. **AI准备**：选择「AI 先安排」或「逐项审阅」，核对外发范围和文本请求次数，允许后点「准备这一章」。前者自动应用明确的说话人与常规表演，留下疑点；后者审阅后应用。两者都保留人工改动，不代替听评。
3. **试听与修改**：先在「需要你处理」集中确认疑点、为角色选声音；可试听已有声音、上传 WAV / MP3 参考（不超过 30 秒、10 MB），或描述创建候选。点「生成待办」或「生成所选」，核对范围与请求额度后开始。有效编辑自动保存，生成会等待相关保存。逐句或整章试听，核对漏字、重复、声音身份和表演；不满意就地修改再制作。整章试听需要的母版自动准备，完成后继续播放；拖进度条可定位，点「回到当前播放」恢复跟随。
4. **导出成品**：确认实际试听结果，再点「导出成品」或右上角「导出」，选择 WAV / MP3；需要时调整「片段间隔（秒）」并「保存间隔」。点「确认检查并导出」，完成后在「已导出的文件」下载。两个格式使用同一母版，导出本身不调用配音模型。

**「确认检查并导出」同时将当前匹配音频的待检查项确认为通过。不要把它当作未经试听的普通下载按钮。**

## 三个常用调整

| 想做什么 | 怎么操作 |
|---|---|
| 换角色或某一句的声音 | 从「需要你处理」或当前句「选声音」进入，试听后选「角色在本章」或「仅这一句」。本章换声保留已有单句覆盖；首次绑定也建立未来新增台词的默认声音，界面会提示。 |
| 让一句更有表演感 | 就地修改「表演指导」，例如“前半句低声，‘别走’稍重，结尾停顿”；有效内容自动保存，再重新制作。只写怎么说，环境音放到「声音背景」。 |
| 让对话连贯、加环境音 | 勾选两条或更多连续对白，点「一起演绎」设置共同指导并生成；选一句或一组，点「声音背景」集中设置环境、音效和音乐。改组内一句会重做整组；旧声音从「历史与版本」或面板的「历史声音与详细设置」查看。 |

右侧「原文」可查看原文、前后文和当前朗读文字；修改朗读文字不会覆盖原文。窄屏点击片段，会打开同样的设置面板。

需要拆分、合并时，在片段的「更多设置」操作。配置不一致时先核对差异；新片段需要重新生成，原通过状态不会直接继承。

## 看懂状态

| 状态 | 下一步 |
|---|---|
| 待确认 | 核对说话人和声音身份，再确认。 |
| 待生成 | 补齐参考与配置，生成本条或待办。 |
| 待更新 | 正文或发声设置已变，旧音频保留；重生成后再检查。 |
| 待检查 | 已有匹配音频，尚未通过听评。 |
| 需返工 | 调整后重生成；批量「生成待办」只包含**已勾选**的需返工项。 |
| 结果不明 | 供应商可能已处理请求。先核对记录，明确接受可能重复计费后再重试。 |
| 已排除 | 不参与当前朗读与导出；不要用排除来隐藏漏句。 |

## 中断或失败时

- **生成失败**：旧的有效音频不会被删除。先看错误原因，再重试失败条目。
- **批次停止**：在「任务记录」点「选择余下片段继续」，核对后再「生成所选」。这会创建新任务，不会暗中恢复旧批次；结果不明项默认不选。
- **新版不如旧版**：在「音频版本」选择「上一版」或「最近通过版」，核对设置差异后恢复。角色归属不会被旧音频偷偷改回。
- **保存冲突**：比较「本页编辑」与「工作区当前内容」，再选择用本页编辑更新这一处，或「保留工作区内容」。没完成的输入可从左侧「本机暂存」查看、恢复并返回编辑；不要反复提交旧窗口。
- **服务失联**：恢复本机服务后等工作台刷新，再主动播放；旧播放不会自动继续。关闭浏览器不会停止仍在运行的本机生成服务。
- **导出被拦截**：先处理未确认身份、原文缺口、缺失/过期音频及需返工项。全章排除也不能正式导出。

## 模型、费用和保存

**查看或更改保存位置**：「设置与连接 → 项目保存位置」显示总目录，可以复制路径。点「更改位置」，在文件夹选择窗口中选择空文件夹（也可新建），确认显示的目录后点「迁移全部项目」。取消选择不会改变保存位置。请先保存编辑、停止试听并等待任务结束；迁移完成自动使用新位置，原资料保留，下次双击启动也使用新位置。

总目录下，每个项目都有与项目名称相同的文件夹，存放它的音频和成品；改项目名称时目录同步更新。正文、角色和任务保存在总目录的共用数据库中，音色库也共用。**不要只复制某一个项目文件夹作为完整备份。**

「设置与连接」→「多模态模型名称」可输入 Kunpo 支持的完整名称，再「保存模型设置」。默认是 `gemini-3.8-flash`；分析面板也可只为本轮指定模型。更换默认模型不会重跑旧任务。

文本分析会发送章节文字及相关角色资料；配音会发送朗读正文、表演要求和参考声音。模型调用、重生成和新文本试音可能计费；已有音频的本地试听、合并与导出不调用配音模型。工具不设置文本输出 token 上限，供应商仍可能限流或截断。

编辑时留意「已保存」「保存中」或「本机暂存」。有效内容自动保存；输入法过程、未完成空正文或数字先保留本机，主动作会等待相关保存。正常操作复用范围相符、有效且额度足够的授权；结果不明须明确决定才重发。项目保存在本机数据目录，关闭页面不等于删除。请备份**整个工作区**，不能只复制数据库。启动、停服备份和恢复步骤见 [README](../README.md#停止备份与恢复)。
