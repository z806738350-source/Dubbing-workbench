# 配音工作台使用说明

适用版本：本地首版（2026-10-01）。当前支持**逐条干声配音**；多人对戏、背景音乐和场景音效尚未开放。

## 先完成一章

1. **建项目、导入章节**：左上角「新建项目」→ 章节旁「＋」→ 选择 UTF-8 的 TXT / Markdown，或粘贴原文。检查章节名和原文预览，再导入。Markdown 按纯文本读取。
2. **整理剧本**：点「整理剧本」→「生成校对草稿」。检查每条原文和说话人；有问题点「校对本条」，修改后「保存本条校对」。确认替换当前剧本，再点「应用校对稿」。AI 草稿不会自动覆盖正文。
3. **准备声音**：打开「音色库」→「添加参考」，上传 WAV / MP3（不超过 30 秒、10 MB）。优先用单人、清晰、少噪声的素材；可以先试听，或主动点击「生成新文本试音」（付费）。
4. **给角色配声**：打开「管理角色」，为旁白及各角色选择默认音色，再「保存角色」。首次绑定会补齐本章尚无音色的相应片段。逐条核对人物归属；勾选片段后可批量「确认归属」。
5. **生成**：点「生成待办」。也可勾选几条后「生成所选」，或在右侧「生成本条」。生成期间本章只读；进度、失败和中断原因可在「任务记录」查看。
6. **试听与返工**：逐条点播放，核对漏字、重复、角色声音及表演。满意后点该行的勾选图标「检查通过」；不满意则调整右侧设置、保存，再「重新生成」。
7. **整章试听**：底部「准备试听」完成后点播放。拖进度条定位；手动浏览列表会暂停跟随，点「回到当前播放」恢复。
8. **导出**：右上角「导出」，选择 WAV 或 MP3；需要时先调整「片段间隔（秒）」并「保存间隔」。听完确认无误，再点「确认检查并导出」。完成后重新打开导出窗口，在「已导出的文件」下载。

**「确认检查并导出」同时将当前匹配音频的待检查项确认为通过。不要把它当作未经试听的普通下载按钮。**

## 三个常用调整

| 想做什么 | 怎么操作 |
|---|---|
| 只换某一句的声音 | 选择片段，在「实际音色」指定参考，保存后重生成。本条覆盖不随角色默认音色自动改变。 |
| 改角色的默认声音 | 在角色档案修改；已有条目是否跟随，按「应用到本章使用角色默认的片段」的影响预览决定。其他已存在章节不静默改声。 |
| 让一句更有表演感 | 在「表演指导」写具体要求，例如“前半句低声，‘别走’稍重，结尾停顿”。只写怎么说，不把台词或背景音写进去。 |

右侧「原文」可查看原文、前后文和当前朗读文字；修改朗读文字不会覆盖原文。窄屏点击片段，会打开同样的设置面板。

需要拆分、合并时，在片段的「更多设置」操作。配置不一致时先核对差异；新片段需要重新生成，原通过状态不会直接继承。

## 看懂状态

| 状态 | 下一步 |
|---|---|
| 待确认 | 核对说话人和声音身份，再确认。 |
| 待生成 | 补齐参考与配置，生成本条或待办。 |
| 待更新 | 正文或发声设置已变，旧音频保留；重生成后再检查。 |
| 待检查 | 已有匹配音频，尚未通过听评。 |
| 需返工 | 调整后重生成；批量「生成待办」只包含**已勾选**的需返工项。 |
| 结果不明 | 供应商可能已处理请求。先核对记录，明确接受可能重复计费后再重试。 |
| 已排除 | 不参与当前朗读与导出；不要用排除来隐藏漏句。 |

## 中断或失败时

- **生成失败**：旧的有效音频不会被删除。先看错误原因，再重试失败条目。
- **批次停止**：在「任务记录」点「选择余下片段继续」，核对后再「生成所选」。这会创建新任务，不会暗中恢复旧批次；结果不明项默认不选。
- **新版不如旧版**：在「音频版本」选择「上一版」或「最近通过版」，核对设置差异后恢复。角色归属不会被旧音频偷偷改回。
- **提示资料已更新**：通常是另一页面已保存。保留需要的输入，重新打开当前资料后再改，不要反复提交旧窗口。
- **服务失联**：恢复本机服务后等工作台刷新，再主动播放；旧播放不会自动继续。关闭浏览器不会停止仍在运行的本机生成服务。
- **导出被拦截**：先处理未确认身份、原文缺口、缺失/过期音频及需返工项。全章排除也不能正式导出。

## 模型、费用和保存

「设置与连接」→「多模态模型名称」可输入 Kunpo 支持的完整名称，再「保存模型设置」。默认是 `gemini-3.8-flash`；分析面板也可只为本轮指定模型。更换默认模型不会重跑旧任务。

文本分析会发送章节文字及相关角色资料；配音会发送朗读正文、表演要求和参考声音。模型调用、重生成和新文本试音可能计费；已有音频的本地试听、合并与导出不调用配音模型。工具不设置文本输出 token 上限，供应商仍可能限流或截断。

编辑时留意「保存」与「已保存」；未保存输入不能直接用于生成。项目保存在本机数据目录，关闭页面不等于删除。请备份**整个工作区**，不能只复制数据库。启动、停服备份和恢复步骤见 [README](../README.md#停止备份与恢复)。

本次指定章节的验收工作区位于 `data/final-acceptance-20261001/workspace`，运行时入口为 [最终听评工作区](http://127.0.0.1:4327/)。普通默认工作区入口是 [本机工作台](http://127.0.0.1:4318/)，两者数据独立。
