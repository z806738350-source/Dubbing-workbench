# 配音工作台使用说明

适用版本：macOS 本机体验升级版（2026-10-03 更新，内部试用）。支持单句配音、声音创建、多人一起演绎和声音背景；生成效果需要实际试听。快速开始见 [四步入门](ux-redesign/quick-start.md)。

**打开工具**：macOS 双击项目根目录的「启动配音工作台.command」，浏览器会自动打开 [本机工作台](http://127.0.0.1:4318/)。使用独立试用包时，解压后双击包内的「启动体验版.command」。首次使用需安装 Node.js 22.13+ 和 FFmpeg / FFprobe；启动项会准备项目依赖。使用期间保留启动窗口，停止按 Control+C；重复双击会打开已运行页面。

**第一次使用**：可先点「免费试听演示」熟悉播放器。演示使用本机语音，不代表 Seed Audio 的生成效果，也不产生模型费用。真实制作前，到左侧「设置与连接」检查密钥和音频处理状态；缺少配置时，按 [README 的启动说明](../README.md#启动) 或试用包内 README 完成配置。

## 先完成一章

1. **导入文字**：新建或选择项目，点「导入章节」，选择 UTF-8 的 TXT / Markdown（文件最多 4 MB），或粘贴原文。检查章节名和预览，再点「导入并进入AI准备」。Markdown 按纯文本读取，原文件内容保留；不进入 AI 准备时，可点「仅导入并本地分段」。非空草稿关闭后仍可找回。
2. **AI准备**：选择「AI 先安排」或「逐项审阅」，核对外发范围和文本请求次数，允许后点「准备这一章」。前者自动应用明确的说话人与常规表演，并在这次文本分析中按语义拆短尚未制作的长台词，留下疑点；后者先显示建议与分段预览，选择后应用。拆分保留原文顺序、角色、声音和制作参数。已有有效音频、对戏组、声音事件或涉及「前半句／后半句」等位置的人工表演不会被自动重排，会留待处理。两者都保留人工改动，不代替听评。
3. **试听与修改**：先在「需要你处理」集中确认疑点、为角色选声音；可试听已有声音、上传 WAV / MP3 参考（不超过 30 秒、10 MB），或描述创建候选。点「生成待办」或勾选台词后点「生成所选」，查看台词范围、纯人声／声音背景、复用声音和新请求次数，再点「开始生成…」。有效编辑自动保存，生成会等待相关保存。逐句或整章试听，核对漏字、重复、声音身份和表演；不满意就地修改再制作。整章试听需要的母版自动准备，完成后继续播放；拖进度条可定位，点「回到当前播放」恢复跟随。
4. **导出成品**：确认实际试听结果，再点「导出成品」或右上角「导出」，选择 WAV / MP3；需要时调整「片段间隔（秒）」并「保存间隔」，重新整章试听后导出。点「确认检查并导出」，面板留在原处显示任务和成品；完成后，在「已导出的文件」按实际编排和完成时间下载「当前结果」。也可先关闭，稍后重新打开查看。文件缺失时没有可用下载，源音频完整可重新导出当前版本。两个格式使用同一母版，导出本身不调用配音模型。

**「确认检查并导出」同时将当前匹配音频的待检查项确认为通过。不要把它当作未经试听的普通下载按钮。**

「AI 已安排」表示建议已进入制作初稿，不表示你已确认声音效果。「允许上述范围」只授予相应调用权限；真正开始制作仍需点击生成按钮。生成所选范围时，匹配且未标记重做的声音会复用，不为复用再次调用配音模型；标记重做的声音会列为新请求，先看清范围再开始。

顶部会分别显示台词句数和声音单元数。几句一起演绎属于一个声音单元，按整段生成、听评和导出；切换纯人声与带背景声后，按上方「整章使用」判断当前编排，不能只看某个单句的成功记录。

## 常用调整

| 想做什么 | 怎么操作 |
|---|---|
| 换角色或某一句的声音 | 从「需要你处理」或当前句「选声音」进入，选择「已有声音」「上传参考」或「描述创建」。先看「应用范围」的选中项、受影响台词数量，再点「用这个声音」。本章换声保留已有单句覆盖；首次以本章范围为角色绑定，也建立未来新增台词的默认声音，界面会提示。 |
| 让一句更有表演感 | 就地修改「表演指导」，例如“前半句低声，‘别走’稍重，结尾停顿”；有效内容自动保存，再重新制作。只写怎么说，环境音放到「声音背景」。 |
| 让对话连贯 | 勾选两条或更多连续对白，点「一起演绎」，填写接话要求，核对成员和授权后点「生成这段对话」。成功后使用整段声音；正文中的组头提供「试听整段」「调整这段」「重做这…句」。改组内一句后，再制作会重做整组。 |
| 加环境、音效或音乐 | 选一句或一组，点「声音背景」→「添加声音」，填写描述和位置，勾选「加入这次场景」，点「完成编辑」，再点「应用并生成带背景声」或「再做一版」。已保存的声音也可在列表点「加入场景」；仅保存、未采用的声音不会加入本次场景。 |
| 恢复逐句配音 | 点组头「调整这段」→「高级设置与请求记录」→「取消一起演绎…」，核对各句纯人声后确认。整段历史保留；缺少或过期的单句纯人声需要补生成，取消本身不会自动生成或裁切整段音频。 |

**选声范围**：从单句进入时默认「仅这一句」，从角色问题进入时默认「角色在本章」。前者只改当前句，后者更新本章沿用角色声音的台词。可以展开「查看受影响台词」核对。若选声期间内容发生变化，点「重新核对当前范围」，再确认应用。

**描述创建声音**：填写声线、年龄感和气质，核对授权后点「生成一个候选」；每次制作一个候选。完成后「试听候选」，满意再命名并点「用这个声音」，自动保存到音色库并应用到当前范围。若提示「声音已保存，尚未应用」，保留这份声音，核对范围后继续应用。

**删除参考素材**：删除后不再显示音色卡片，也不计入音色库数量；已有音频和历史中的音色名称保留。若素材正在被任务或试听读取，列表显示删除进度，结束后自动清理文件。停用、归档的声音仍保留在库中，可以重新启用。

**声音背景面板**：上方显示整章正在使用的声音。「纯人声／带背景声」只切换查看和编辑的版本；实际选用在「试听与选用」操作，已选用显示「正在使用…」。人工听评通过、标记重做都只记录检查结果，不发起生成。修改下一版的背景与表演后，点底部「再做一版」或「应用并生成带背景声」才会请求模型、制作新音频。

**AI 声音建议**：展开「让 AI 提供声音建议」，在「分析权限与模型」允许本次分析后，点「分析声音建议」。在「本次结果」查看建议，勾选需要的声音，再点「加入选中的…个声音」；加入场景本身不发生成请求。每次新分析会自动回到本次结果。想找旧建议时，点「历史建议 · …」，选择对应时间；下拉列出建议数量和是否曾加入，实际描述、位置与推荐理由在同一区域展示，返回「本次结果」可看最新一轮。需要复用时，勾选旧建议，点「重新加入选中的…个声音」：即使曾经加入后又移除，或分析时的设置已变化，也可按当前有效台词位置重新加入。此操作免费，不重新调用AI分析或制作声音；当前已加入的相同声音会显示「已在当前场景」，不重复添加。原台词已删除、拆分或位置无效的项目会说明原因，不能套到另一句上。重新加入保留现有背景、共同要求与历史；之后若要把新设置变成音频，再由你点生成新版。

分析只建议新增声音，不重复建议已加入或已明确移除的声音。「分析完成，本次没有新增声音建议」表示模型返回了空建议列表，已有背景与共同要求仍保留；可继续编辑或手工添加声音，无需为了空结果反复分析。旧历史可查看、勾选并明确重新加入；仅查看不会改变场景或发起生成。AI不自动加回已移除的声音，但用户主动复用历史建议可以加回。

面板右上角的问号图标可打开「操作说明」，集中查看试听、选用、人工检查、历史复用和生成规则。关闭说明会回到原操作位置，编辑内容保留。当前请求范围、生成进度、授权额度及需要处理的错误仍显示在对应操作处。

面板内播放当前声音或历史声音时，原试听按钮会变成「暂停这份声音」「暂停已有声音」或「暂停声音…」，可直接暂停，无需关闭面板。点另一份试听会切换播放目标。参考素材停用会影响下一次生成，已有匹配、可用的音频仍可试听；通过当前听评及其他导出检查后仍可导出。

**原生背景存在感（试验）**：在声音背景的「历史声音」下方独立选择「下一次生成的背景存在感」，默认「清楚」，也可明确选择自然、轻或未指定。手工填写「希望场景怎样呈现？」和使用 AI 声音建议都会使用这个选择；AI 分析会接收当前存在感并据此组织声音描述。已有明确的选择和历史音频不变，旧缺省设置在下一次明确分析、核对模板或生成操作前保存。首次使用且没有显式模板或场景历史时，默认采用 v4。已保存的旧模板和旧声音不会自动升级；选择轻、自然或清楚后，生成按钮旁会说明当前旧模板不支持此选择，点「查看并切换到 v4」，比较当前提示和新模板提示，再点「使用这个模板」。核对会等待设置保存，不发送音频请求；启用后，再明确点击生成新版才会请求模型。也可从「高级设置与请求记录 → 下一次生成的提示模板」选择「场景 v4 · 背景存在感（试验）」，点「查看模板差异」后应用。存在感选项用于 AI 分析，并在此模板的下一次生成生效，已有声音保留。发现描述要求「极微弱、几乎不可闻」等与选择矛盾时，会就地提示并阻止生成；不悄悄改写你的描述。请修改相应声音或共同要求。历史建议重新加入时也会按当前存在感核对，避免把冲突要求重新带回。编辑区标题前的箭头可展开或收起手工背景与表演设置。

新模板仍由模型一次联合生成旁白／对白与已采用的环境、音效、音乐，不在本机另行叠加。背景描述最多 1500 个字符，按界面的字符计数判断；超长时先缩短描述。音乐可在「指定音乐转折（可选）」按真实台词、短引文和出现次数定位，并分别填写音乐发展与音量变化。“转为宁静”不自动等于音量淡出。**这些都是生成意图，功能仍处于试验；必须实际试听背景是否可辨、正文是否完整及转折是否合适，不能因选了「清楚」或请求成功就认定效果通过。**旧 v2／v3 声音与模板可继续保留。

**复用历史声音**：在声音背景或一起演绎面板展开「历史声音 · …版」，每份都有编号、时间、时长和可用状态。先点「试听声音…」比较，试听不改变整章。显示「可直接使用」的点「使用声音…」；显示「旧设置 · 需核对」的点「核对并恢复声音…」，看清表演、背景、模板差异，以及将替换或恢复的已采用背景，再点「恢复并使用这份声音」。未采用的背景草稿会保留，不加入这份声音。两种操作都复用已有音频，不发生成请求。

恢复不会撤销后来改正的台词、角色、参考声音或数值设置；这些内容不兼容，或旧编译版本不能精确重现时，旧声音仍可试听，无法恢复使用。预览之后内容又被修改，会要求重新核对，不覆盖新编辑。文件损坏或缺失时无法复用。恢复后查看当前人工听评状态，必要时重新试听并检查；「当前保留」不等于「当前使用」，只有后者进入整章试听与导出。

右侧「原文」可查看原文、前后文和当前朗读文字；修改朗读文字不会覆盖原文。窄屏点击片段，会打开同样的设置面板。

长台词优先在「AI整理 → AI先安排 → 准备这一章」处理；再次准备已整理章节时，也会检查长台词，不必重新导入或重建整章。需要单独调整时，点击台词正文，在「台词编辑」顶部点「拆分这条」，让 AI 按语义拆短，查看编号段落，再点「应用这…条」。不需要输入字符位置，预览不会自动生成声音。AI 拆分使用已配置的文本模型并计入文本请求；应用分段本身不调用配音模型。普通人工表演沿用到各子条，涉及原句具体位置的指导需核对。旧音频和父片段历史保留，子条需要重新生成，原通过状态不会直接继承。合并在「更多设置」操作，配置不一致时先核对差异。已被旧版手动切断词语的相邻两条，先按原文合并，再重新 AI 准备；系统不会悄悄改写已经保存的正文。

## 看懂状态

| 状态 | 下一步 |
|---|---|
| 待确认 | 核对说话人和声音身份，再确认。 |
| 待生成 | 补齐参考与配置，生成本条或待办。 |
| 待更新 | 正文或发声设置已变，旧音频保留；重生成后再检查。 |
| 待检查 | 已有匹配音频，尚未通过听评。 |
| 需返工／需要重做 | 标记只记录问题。顶部「重做否决项」只安排被标记的实际声音单元；也可在声音面板点「再做一版」。生成所选会将匹配但被标记重做的声音列为新请求，其他匹配声音复用。 |
| 新结果待核对／结果不明 | 供应商可能已处理请求并计费；已有声音和历史保留。先试听已有声音、查看这次记录，再决定是否再次发送。 |
| 已排除 | 不参与当前朗读与导出；不要用排除来隐藏漏句。 |

## 中断或失败时

- **生成范围已变化**：面板显示「内容已变化，本次未发送」时，点「重新核对生成范围」。这是免费重新计算；查看更新后的范围，再决定是否开始生成。核对期间关闭面板、切章或打开另一份计划，旧响应不会重新打开或覆盖新面板。
- **导入回执未确认**：重新打开同项目「导入章节」，点「恢复这次导入回执」，会核对同一次导入，不另建一章。若显示「打开已导入章节」，只恢复打开原章节，不再次创建或发起 AI 请求。浏览器提示草稿未可靠暂存时，先复制原文保留，不继续导入。
- **新结果待核对**：从「需要你处理」点「核对生成任务」，优先「试听已有声音」和「查看这次记录」。两者都不会重发请求。决定再次发送时，核对范围和制作授权，勾选可能再次计费的提示，再点「再次提交 1 次请求」。若没有已有声音，先查看记录。
- **关闭生成面板**：尚未提交时关闭即可退出本次准备；已经提交后，关闭面板不会撤销请求，进度与结果可在左侧「任务记录」查看。需要停止后续派发，在章节上方的任务进度条点「停止后续」；已经发送的请求可能仍会完成并计费。
- **生成失败**：旧的有效音频不会被删除。先看原处提示和请求记录；明确未提交的错误先修正设置，结果未确认时先核对现有结果。
- **声音接口已暂停**：接口暂停与制作授权分别记录；显示「还可请求」不代表接口已经恢复。核对「设置与连接」中的接口配置、供应商权限与账户额度后，回到原生成面板，勾选「已核对接口权限与额度，恢复本次声音请求」，再点击生成。声音候选、一起演绎及声音背景也在各自面板就地恢复；有效授权可继续使用。勾选本身不发请求。若接口再次拒绝，会重新暂停，需要再次核对；「结果不明」的重发决定仍须单独确认。
- **时长超出范围（DurationOutOfRange）**：单次输出最长120秒，参考录音最长30秒。优先在「AI整理 → AI先安排」重新准备，AI 会为合适的长单条选择自然句子或分句边界；也可点击台词正文，点右侧顶部「选声音」旁的「拆分这条」，查看 AI 分段预览后应用。无需数数字符。慢语速需要更短的段落。左侧复选框用于批量选择。生成面板也会提示长单句或整组并提供「返回编辑」。字数只是提醒，不是精确时长保证；AI 分段计入文本请求，应用不产生配音请求，原文、音色和设置保留。旧版本若已因此暂停接口，拆短后核对参考及接口，再在生成面板明确恢复。
- **批次停止**：「任务记录」若提供「选择余下片段继续」，可自动勾选余下片段，且排除结果不明项；否则回到章节，勾选需要继续的台词。核对后点「生成所选」，会创建新任务。结果不明项先单独核对，再决定是否重发。
- **新版不如旧版**：在声音面板展开「历史声音」，按编号试听并选用，或核对差异后恢复。也可使用「恢复上一版／恢复最近通过版」快捷按钮；恢复不会重新生成，角色归属不会被旧音频偷偷改回。
- **保存冲突**：比较「本页编辑」与「工作区当前内容」，再选择用本页编辑更新这一处，或「保留工作区内容」。没完成的输入可从左侧「本机暂存」查看、恢复并返回编辑；不要反复提交旧窗口。
- **服务失联或回执无法读取**：保留编辑，恢复本机服务后等工作台刷新；先查看「任务记录」和已有声音，导入则回原导入面板核对。不要因为失联、本地服务失败或回执未读就立即再生成。再主动播放，旧播放不会自动继续。关闭浏览器不会停止仍在运行的本机生成服务。
- **导出被拦截**：先处理未确认身份、原文缺口、缺失/过期音频及需返工项。全章排除也不能正式导出。

## 模型、费用和保存

**查看或更改保存位置**：「设置与连接 → 项目保存位置」显示总目录，可以复制路径。点「核对资料与空间」，查看参考录音、生成声音、整章试听母版和导出成品的数量、大小及缺失文件；仅可重建的母版缺失，会显示可免费重建。原件或成品缺失时先找回文件或恢复完整备份，不能迁移。

点「更改位置」也会先核对资料，再打开文件夹窗口。选择空文件夹（也可新建），确认显示的目录后点「迁移全部项目」。取消选择不会改变保存位置。请先保存编辑、停止试听并等待任务结束；迁移完成自动使用新位置，原资料保留，下次双击启动也使用新位置。

总目录下，每个项目都有与项目名称相同的文件夹，存放它的音频和成品；改项目名称时目录同步更新。正文、角色和任务保存在总目录的共用数据库中，音色库也共用。**不要只复制某一个项目文件夹作为完整备份。**

**删除项目**：打开「当前项目」下拉列表，点击对应项目右侧的垃圾桶。核对面板列出的章目与原始音频、母版、导出文件数量，再点「删除上面列出的项目资料」。这份范围预览就是最终确认。若核对后有新章节、编辑或产物，原处显示本次未删除；点「重新核对删除范围」，看清新范围后再决定。

删除会移除项目的章节、角色、制作记录及专属文件。共用音色和声音创建素材保留；若共用音色仍引用本项目的音频，按原处提示先处理引用。删除当前项目会停止当前播放，并进入剩余项目；全部删除后回到空工作区。该项目仍在生成、分析或保存时，等操作结束后再删。需要恢复已删除项目时，使用删除前的完整工作区备份。

总目录里的顶层文件用途如下，不应当作为杂项直接清理：

| 文件或目录 | 用途 |
|---|---|
| `workbench.sqlite` | 总数据库，记录全部项目、章节、角色、音色关联和任务。 |
| `workbench.sqlite-wal`、`workbench.sqlite-shm` | 运行中的数据库辅助文件，由程序管理；不要运行中手动删除。 |
| `voices` | 跨项目共用的参考声音。 |
| `audio` | 共用的声音候选、测试样音，以及旧布局尚未归入项目的音频。 |
| `masters`、`exports` | 旧布局的母版与导出目录；启用项目文件夹后，章节成果归入各项目目录，顶层可能为空。 |
| `runtime.json` | 本机服务的进程、端口标记，正常启动和停止时自动管理。 |

空目录保留即可；已登记的音频应通过工具管理，不要在 Finder 直接删文件。更改保存位置会复制总库、共享素材及全部已登记项目目录，在新位置创建运行标记；旧位置原资料保留，但之后不会跟随新位置同步更新。核对新位置能打开项目、试听并导出后，再自行决定是否保留旧副本。

「设置与连接」→「多模态模型名称」可输入 Kunpo 支持的完整名称，再「保存模型设置」。默认是 `gemini-3.8-flash`；分析面板也可只为本轮指定模型。更换默认模型不会重跑旧任务。

文本分析会发送章节文字及相关角色资料；配音会发送朗读正文、表演要求和参考声音。模型调用、重生成和新文本试音可能计费；已有音频的本地试听、合并与导出不调用配音模型。工具不设置文本输出 token 上限，供应商仍可能限流或截断。

编辑时留意「已保存」「保存中」或「本机暂存」。有效内容自动保存；输入法过程、未完成空正文或数字先保留本机，主动作会等待相关保存。临时清空正文不会自动排除台词；确实不朗读时，在「更多设置」勾选「从朗读中排除，保留原文记录」，组内台词须先取消一起演绎。正常操作复用范围相符、有效且额度足够的授权；结果不明须明确决定才重发。

授权面板的「允许文本请求次数」「允许音频请求次数」按实际请求计算，几句一起演绎通常只占一次音频请求；查看生成范围列出的次数，不按台词数猜测。已发送失败或结果不明的请求仍占用额度，未发送部分可释放。「还可请求」是本次授权的剩余次数，不是供应商账户余额，也不保证接口可用。「停止后续授权」只停止尚未发送的请求，不撤销已经外发的请求或费用。

**本机暂存的入口归属**：草稿按浏览器打开地址、实际工作区和页面区分。生产入口 `127.0.0.1:4318` 与开发入口 `127.0.0.1:5173` 的暂存不同；改主机地址或端口前，先在原入口保存或复制编辑。切到另一个工作区或同 ID 的备份目录，不会自动套用原库草稿。需要找回时，回原地址和原工作区处理；旧版归属未确认的暂存保留供查看、复制或明确放弃，不自动写入新工作区。

项目保存在本机数据目录，关闭页面不等于删除。请先停止服务，再备份「设置与连接」显示的**整个工作区**，不能只复制数据库或某个项目文件夹。启动、停服备份和恢复步骤见 [README](../README.md#停止备份与恢复)；其中的示例目录应替换成你的实际保存目录。
