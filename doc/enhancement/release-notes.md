# 增强阶段使用说明

## 声音创建

进入音色库 → 描述声音 → 保存描述 → 核对样文与费用 → 生成候选。候选生成完成后先试听，再命名保存到音色库，最后到角色档案明确绑定。保存和本地切换不调用模型。创建与上传参考可以同时使用。

描述改动不覆盖旧候选；历史显示各次实际描述。结果不明可能已计费，先核对任务记录，再明确决定是否再次生成。同一候选重复保存只得到同一个音色。

## 多人干声对戏 · 实验

选择同章连续台词 → 创建连续对戏组 → 核对真实成员和配置冲突 → 保存待生成组 → 核对整组提示与费用 → 生成并启用。共同音频只播放一次，以整组高亮。改一处需整组返工，不能承诺混合声音逐句无损替换。

同配置返工失败保留已有匹配音频；正文变动后的旧声音会显示待更新。解除分组先查看各单条能恢复什么，缺失声音留待生成，不自动付费补齐。

组内清空或排除台词前需解除分组。旧异常组会显示“需修复”，可以查看历史和解除预览后明确解除；解除恢复单条干声，场景历史保留，缺干声时不会以旧场景补位。

## 场景生成 · 实验

在单元面板选择场景版本，手工添加声音事件或明确开启场景建议。建议只在逐项勾选并应用后生效；正文、角色不自动改变。采用事件需指明对应成员、前/中/后位置及依据，持续事件需完整边界。

核对事件与费用后生成场景版本。干声与场景各自保留版本，本地切换仅使用已保存且匹配的声音。目标版本缺失时需要另行明确生成；场景重跑不会挤掉干声。正文或成员改变后先复核事件；即使改回原文，也需明确确认，不猜时间、不自动忽略失效事件。

持续事件的结束位置不能早于开始位置。旧反向范围会显示待复核，校正后再生成；保存失败时本机草稿保留。

## 草稿、恢复与导出

未保存输入按页面暂存；“查看本机草稿”可逐份处理遗留版本。活动页面的草稿在原页处理，恢复旧稿仍保留其修订，遇到真实冲突继续拒绝覆盖。

完整结果补登记后可能只在历史里，需试听并明确选择；结束任务不会因此继续运行。不同输入的历史只能试听或经差异预览恢复，检查不会沿用到另一段音频。

正式导出仍要求内容、角色身份、当前音频编排、检查四层成立。有效源声音可以纯本地重建母版、WAV/MP3；参考被停用或删除不要求重新付费生成。

## 验证边界

工程验证、真实接口产物和人耳听评分别记录。真实样本可解码并不证明无漏读、错人或遮蔽正文。本轮声音效果保持待听评；对戏与场景入口明确为实验。没有供应商账单时，只报告实际请求和 unknown 风险，不推算成账单。
