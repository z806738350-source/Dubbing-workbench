## 实现采用既有机制

- 助手业务调用复用 `domain`、`analysis`、`experience`、`worker`；HTTP 与助手共用音频可用性检查。不提供任意 action、HTTP、文件路径、SQL 或 shell 工具。
- 委托下产生的安排记录 AI 来源；明确审批和人工听评分开。人工保护字段、原文范围和费用守卫仍在业务执行边界生效。
- 队列与关闭流程使用真实在途记录与 drain；同章任务锁保留。跨章和试音共用音频槽，本地整理与网络请求分开。
- 本地媒体处理另在共有进程入口限制为一个进程，覆盖上传、校验、截图解码和渲染，避免旁路入口超过处理上限。
- 没有新增依赖。完整音频的完整性记录用于文件系统与数据库不能同时提交的崩溃恢复；附件摘要用于确保预览、发送和迁移的是同一份像素。业务对象版本与去重继续使用版本号、主键、事务和稳定操作记录。
